07. Protocol Layer Explanation

Application — DHCP

Discovers a server, offers an address, requests the address and acknowledges the lease (DORA).

Transport — UDP

Uses UDP ports 67 and 68 for DHCP server and client communication.

Network — IPv4

Routes packets between 192.168.1.0/24 and 192.168.2.0/24. DHCP relay helps forward requests from another subnet.

Data Link — Ethernet

Ethernet frames deliver data across each local network link using MAC addresses.

Physical — Transmission

Network interfaces and cables carry bits between connected devices.

08. Key Findings

  • DHCP reduces the need for manual IP configuration.
  • Each subnet requires the correct address pool and default gateway.
  • Routers do not normally forward local DHCP broadcasts.
  • DHCP relay allows clients in another subnet to contact a centralized DHCP server.
  • Correct subnet configuration prevents assigning addresses from the wrong network.
